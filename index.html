Bot che raccoglie notizie da RSS e blog, le riassume con un LLM e le invia in automatico su Telegram (chat privata e canale).

Il progetto combina automazione, integrazione di API e uso di modelli linguistici per creare una pipeline utile e ripetibile.

Progetti ML / Data Science

Implementazioni pratiche di modelli di machine learning su dataset reali: classificazione, regressione e clustering.

Esempi:

  • Random Forest per previsione di target numerici o categorici
  • DBSCAN per clustering di dati
  • Eventuali esperimenti con transformer (es. BERT) e altri modelli preaddestrati

Tecnologie: Python, pandas, scikit‑learn, eventualmente Hugging Face Link: github.com/ectorr01/MNIST-built-model-keras

Firecrawl Scraper & Crawler

Web app in Streamlit che usa Firecrawl per fare scraping e crawling di siti: estrae contenuti, link e struttura partendo da uno o più URL.

Tecnologie: Python, Streamlit, Firecrawl API Link: github.com/ectorr01/firecrawl-streamlit

Edge AI / Computer Vision
